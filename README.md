🔐 Project Overview

This repository contains a complete ISO/IEC 27001:2022 Information Security Management System (ISMS) Toolkit, developed as a full consultant-style project for the IE3102 module.
The toolkit follows industry best practices and aligns with:

ISO/IEC 27001:2022

ISO/IEC 27002:2022

ISO/IEC 27005

PDCA (Plan–Do–Check–Act) Cycle

NIST Cybersecurity Framework

The objective is to simulate a real-world consulting engagement by producing all required documentation, tools, templates, and awareness materials necessary to implement and operate an ISMS.

Review Scope, Asset Registry, Risk Assessment documents.

Follow the Implementation Steps Guide for deployment.
